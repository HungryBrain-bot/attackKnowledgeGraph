# T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder

## The Attack - What Actually Happens
Both APT29 and APT28 are documented using registry run keys (or the
Startup folder equivalent) for persistence, but the direct source
material available for this project is thinner here than for the other
techniques - MITRE's own relationship data cites exactly one source per
group for this technique (Mandiant's "No Easy Breach" for APT29, Trend
Micro's Pawn Storm Dec 2020 report for APT28), and neither could be
retrieved in enough detail to quote the specific mechanism. What's
documented at the technique level: APT29 pairs registry run keys with
obfuscated PowerShell (consistent with "No Easy Breach"'s broader
coverage of the group's PowerShell-heavy tradecraft), and APT28's Pawn
Storm-era tooling includes PowerShell payloads capable of establishing
this kind of persistence.

## The Present Problem
A new registry Run key value is one of the higher-signal persistence
indicators available (far less common than process or file discovery
noise), but on its own it doesn't say how the adversary got there or
what to expect afterward. This case file is also useful as an honest
example of the limits of this project's sourcing discipline this pass:
the edges into T1547.001 are real and cited, but scored at the lower end
of the confidence range specifically because the underlying reports
couldn't be fully retrieved to confirm the mechanism directly, only the
co-citation.
