# T1204.002 - Malicious File

## The Attack - What Actually Happens
The victim opens the file delivered via T1566.001 and enables content
(macros) or the file exploits a parser bug on open. For APT29's Dukes
malware lineage, F-Secure's "The Dukes" report and the general public
record on the group's tooling (POSHSPY, PowerDuke - documented in
Volexity's "PowerDuke" writeup on the 2016 post-election spearphishing
campaigns) describe the same pattern repeatedly: the weaponized document
exists specifically to launch a PowerShell-based backdoor the moment the
macro runs. The file itself carries no persistence or C2 logic of its
own - it's a one-shot loader.

## The Present Problem
"Malicious file executed" is often the first alert a defender actually
sees (EDR catches the process spawn), but a flat technique catalog
doesn't say what process that file is expected to spawn for a given
actor, so triage starts from zero every time. Knowing in advance that
APT29's malicious-file step causally leads to PowerShell - not, say, a
dropped EXE or a scheduled task - changes what the analyst should hunt
for in the same 60 seconds.
